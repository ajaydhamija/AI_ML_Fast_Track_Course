Q1. A single neuron with a monotonic activation, thresholded to classify two inputs, always produces a decision boundary that is:

  • A. A circle
  • B. A straight line
  • C. Two parallel lines
  • D. Any curve, given enough training
Answer B. The rule \(\hat y=1\iff w_1x_1+w_2x_2+b>0\) describes the region on one side of a straight line.

Q2. With \(w=(1,1)\), which bias makes one step neuron compute AND on binary inputs?

  • A. \(b=0.5\)
  • B. \(b=-0.5\)
  • C. \(b=-1.5\)
  • D. \(b=-2.5\)
Answer C. Only \((1,1)\) gives \(1+1-1.5>0\). With \(b=-0.5\) the neuron computes OR; with \(b=-2.5\) it never fires.

Q3. Why can no single neuron compute XOR?

  • A. Its bias cannot be negative
  • B. The two positive points lie on opposite corners, so no straight line separates them from the two negative points
  • C. XOR needs more than two inputs
  • D. The sigmoid saturates at 0 and 1
Answer B. Adding the conditions for \((0,1)\) and \((1,0)\) gives \(w_1+w_2+2b>0\); those for \((0,0)\) and \((1,1)\) give \(w_1+w_2+2b\le0\). Contradiction.

Q4. Two linear layers \(y=W_2(W_1x+b_1)+b_2\) with no activation between them are equivalent to:

  • A. One linear layer \(y=W_2W_1x+(W_2b_1+b_2)\)
  • B. A network with one ReLU hidden layer
  • C. A deeper and more expressive model
  • D. A polynomial of degree 2
Answer A. A composition of linear maps is linear: without a non-linearity, depth adds nothing.

Q5. In the network \(h_1=\text{ReLU}(x_1+x_2)\), \(h_2=\text{ReLU}(x_1+x_2-1)\), \(\hat y=h_1-2h_2\), what is \(\hat y\) for input \((1,1)\)?

  • A. 2
  • B. 1
  • C. -1
  • D. 0
Answer D. \(h_1=2\), \(h_2=1\), so \(\hat y=2-2=0\): the correct XOR output.

Q6. In the same XOR network with ReLU replaced by the identity, the outputs for \((0,0),(0,1),(1,0),(1,1)\) become:

  • A. 0, 1, 1, 0
  • B. 2, 1, 1, 0
  • C. 0, 1, 1, 2
  • D. 1, 1, 1, 1
Answer B. \(\hat y=(x_1+x_2)-2(x_1+x_2-1)=2-x_1-x_2\): a single linear function, which fails at \((0,0)\).

Q7. How many parameters does a dense network 20 → 64 → 32 → 5 have?

  • A. 3,328
  • B. 3,589
  • C. 3,488
  • D. 4,096
Answer B. \(21\times64+65\times32+33\times5=1{,}344+2{,}080+165=3{,}589\).

Q8. A one-hidden-layer network on a single input with \(n\) ReLU units produces a piecewise-linear function with at most how many bends?

  • A. \(n\)
  • B. \(2n\)
  • C. \(n^2\)
  • D. \(2^n\)
Answer A. Each ReLU contributes one kink where its input crosses zero. Depth, not width, gives exponentially many pieces.

Q9. The derivative of the sigmoid can be written as:

  • A. \(\sigma(z)^2\)
  • B. \(1-\sigma(z)\)
  • C. \(\sigma(z)(1-\sigma(z))\)
  • D. \(e^{-z}\)
Answer C. Its maximum is \(0.25\), at \(z=0\).

Q10. For a sigmoid output with binary cross-entropy loss, the output error signal \(\partial L/\partial z^{(2)}\) simplifies to:

  • A. \(a^{(2)}-y\)
  • B. \((a^{(2)}-y)^2\)
  • C. \(-\ln a^{(2)}\)
  • D. \(a^{(2)}(1-a^{(2)})\)
Answer A. The \(\sigma'\) factor of the chain rule cancels against the loss derivative, leaving prediction minus label.

Q11. In the lecture's 2–2–1 example, \(a^{(2)}=0.5447\) and \(y=1\). The loss \(L=-\ln a^{(2)}\) is about:

  • A. 0.455
  • B. 0.788
  • C. 0.545
  • D. 0.608
Answer D. \(-\ln0.5447=0.6075\).

Q12. The hidden error signal is \(\delta^{(1)}_j=\delta^{(2)}\,w^{(2)}_j\,\sigma'(z^{(1)}_j)\). In the lecture's example, \(\delta^{(1)}_2\) is positive while \(\delta^{(2)}\) is negative because:

  • A. \(\sigma'\) is negative
  • B. \(w^{(2)}_2=-0.5\) is negative
  • C. \(x_2\) is smaller than \(x_1\)
  • D. The bias \(b^{(2)}\) is positive
Answer B. \(-0.4553\times(-0.5)\times0.2288=+0.0521\): increasing \(a^{(1)}_2\) would lower the output, so the gradient pushes it the other way.

Q13. A numerical gradient check estimates \(\partial L/\partial\theta\) by:

  • A. \([L(\theta+h)-L(\theta-h)]/(2h)\) for a small \(h\)
  • B. Setting \(\theta=0\) and reading \(L\)
  • C. Averaging the gradients of all parameters
  • D. Running backpropagation twice
Answer A. The central difference agrees with backpropagation to many decimal places when the code is correct.

Q14. With \(\eta=0.5\), the gradient-descent step in the lecture lowered the loss from 0.6075 to:

  • A. 0.5447
  • B. 0.6455
  • C. 0.4377
  • D. 0.3276
Answer C. After the update \(\hat y=0.6455\) and \(L=-\ln0.6455=0.4377\).

Q15. Ten stacked sigmoid layers shrink the error signal reaching the first layer by a factor of at least about:

  • A. \(10^{-3}\)
  • B. \(2.5\)
  • C. \(0.25\)
  • D. \(10^{-6}\)
Answer D. \(\sigma'\le0.25\), so \(0.25^{10}\approx9.5\times10^{-7}\). This vanishing gradient is why ReLU and residual connections are used.

Part B — Assignment

Instructions. Five problems, 100 marks, plus a 20-mark bonus problem (Problem 6). Reference: Lecture 6 reference text.

Problem 1: Single-neuron boundaries and the XOR wall 20 marks

A step neuron outputs $\hat y=1$ if $w_1x_1+w_2x_2+b>0$ and $0$ otherwise, on binary inputs.

(a) With $w=(1,1)$, give a bias for AND and a bias for OR, and verify each on all four inputs. [5]
(b) Find weights and a bias for NAND (output 0 only for $(1,1)$). [4]
(c) Prove that no single neuron computes XOR. [6]
(d) Show that XOR $=$ AND(OR, NAND), and hence that a network with one hidden layer of two step neurons computes XOR. [5]

Show full solution

(a) AND: $b=-1.5$. Sums $x_1+x_2-1.5$ are $-1.5,-0.5,-0.5,0.5$ for $(0,0),(0,1),(1,0),(1,1)$, so only $(1,1)$ fires. OR: $b=-0.5$, sums $-0.5,0.5,0.5,1.5$, so all but $(0,0)$ fire. Any $b\in(-2,-1]$ works for AND and any $b\in(-1,0]$ for OR (with the strict inequality $>0$).

(b) NAND $=$ NOT AND: negate the AND neuron. $w=(-1,-1)$, $b=1.5$: sums $1.5,0.5,0.5,-0.5$, so it fires except at $(1,1)$.

(c) Suppose $w_1,w_2,b$ compute XOR. $(0,0)\mapsto0$: $b\le0$. $(1,1)\mapsto0$: $w_1+w_2+b\le0$. $(0,1)\mapsto1$: $w_2+b>0$. $(1,0)\mapsto1$: $w_1+b>0$. Adding the last two: $w_1+w_2+2b>0$. Adding the first two: $w_1+w_2+2b\le0$. Contradiction, so no such neuron exists. Geometrically the positive points sit on opposite corners of the square and no straight line separates them from the other two.

(d) Table: $(0,0)$: OR 0, NAND 1, AND 0. $(0,1)$ and $(1,0)$: OR 1, NAND 1, AND 1. $(1,1)$: OR 1, NAND 0, AND 0. This is XOR. Network: hidden unit $h_1=$ OR ($w=(1,1)$, $b=-0.5$), hidden unit $h_2=$ NAND ($w=(-1,-1)$, $b=1.5$), output $=$ AND of $h_1,h_2$ ($w=(1,1)$, $b=-1.5$). The hidden layer re-maps the four points so that the output's single line can separate them.

Problem 2: A ReLU hidden layer: forward pass and collapse 20 marks

The network $h_1=\text{ReLU}(x_1+x_2)$, $h_2=\text{ReLU}(x_1+x_2-1)$, $\hat y=h_1-2h_2$ is the lecture's XOR solver.

(a) Tabulate $z_1,z_2,h_1,h_2,\hat y$ for all four binary inputs. [6]
(b) Replace ReLU by the identity, simplify $\hat y$, and show it fails. [5]
(c) For one input $x$, evaluate $f(x)=\text{ReLU}(x)-2\,\text{ReLU}(x-1)+\text{ReLU}(x-2)$ at $x=-1,0,0.5,1,1.5,2,3$ and sketch it. How many bends has it, and why? [6]
(d) Count the parameters of the XOR network (no output bias). [3]

Show full solution

(a) $(0,0)$: $z=(0,-1)$, $h=(0,0)$, $\hat y=0$. $(0,1)$ and $(1,0)$: $z=(1,0)$, $h=(1,0)$, $\hat y=1$. $(1,1)$: $z=(2,1)$, $h=(2,1)$, $\hat y=2-2=0$. All correct. $h_1$ is an OR-like counter, $h_2$ an AND detector: XOR $=$ OR and not AND.

(b) $\hat y=(x_1+x_2)-2(x_1+x_2-1)=2-x_1-x_2$, giving $2,1,1,0$. The output at $(0,0)$ is 2, not 0. Two linear layers collapse into one linear function, which cannot compute XOR.

(c) $f(-1)=0$, $f(0)=0$, $f(0.5)=0.5$, $f(1)=1$, $f(1.5)=0.5$, $f(2)=0$, $f(3)=3-4+1=0$. It is a triangular bump on $[0,2]$ with peak 1 at $x=1$. Three bends, at $x=0,1,2$, one per ReLU unit, where each unit's input crosses zero. Sums of such bumps approximate any continuous function on an interval: the idea behind the universal approximation theorem.

(d) Hidden layer: $2\times2$ weights $+\ 2$ biases $=6$; output: 2 weights. Total $\mathbf{8}$.

Problem 3: A full sigmoid forward pass 20 marks

Use the lecture's 2–2–1 sigmoid network: $x=(1.0,0.5)$, $W^{(1)}=\begin{pmatrix}0.4&-0.2\\0.3&0.6\end{pmatrix}$, $b^{(1)}=(0,0)$, $w^{(2)}=(0.7,-0.5)$, $b^{(2)}=0.1$, binary cross-entropy loss. This time the correct label is $\mathbf{y=0}$ (the track is not hostile).

(a) Compute $z^{(1)}$ and $a^{(1)}$. [6]
(b) Compute $z^{(2)}$ and the prediction $a^{(2)}$. [6]
(c) Compute the loss and compare it with the lecture's loss for $y=1$. [5]
(d) Explain in one sentence why the forward pass does not depend on the label. [3]

Show full solution

(a) $z^{(1)}_1=0.4(1)-0.2(0.5)=0.3$; $z^{(1)}_2=0.3(1)+0.6(0.5)=0.6$. $a^{(1)}=(\sigma(0.3),\sigma(0.6))=(\mathbf{0.5744},\ \mathbf{0.6457})$.

(b) $z^{(2)}=0.7(0.5744)-0.5(0.6457)+0.1=0.4021-0.3229+0.1=\mathbf{0.1793}$; $a^{(2)}=\sigma(0.1793)=\mathbf{0.5447}$.

(c) $L=-[y\ln a+(1-y)\ln(1-a)]=-\ln(1-0.5447)=-\ln0.4553=\mathbf{0.7868}$. For $y=1$ the loss was $-\ln0.5447=0.6075$. The network leans slightly towards “hostile”, so it is penalised more when the truth is “not hostile”.

(d) The forward pass computes the prediction from the inputs and weights only; the label enters only in the loss.

Problem 4: The backward pass 20 marks

Continue Problem 3 with $y=0$.

(a) Compute the output error signal $\delta^{(2)}=\partial L/\partial z^{(2)}$ and the gradients for $w^{(2)}$ and $b^{(2)}$. [6]
(b) Compute $\sigma'(z^{(1)}_j)$ and the hidden error signals $\delta^{(1)}_j$. [6]
(c) Compute the gradients for all four entries of $W^{(1)}$ and for $b^{(1)}$. [5]
(d) Check $\partial L/\partial w^{(2)}_1$ numerically with $h=10^{-4}$. [3]

Show full solution

(a) $\delta^{(2)}=a^{(2)}-y=\mathbf{0.5447}$. $\partial L/\partial w^{(2)}=\delta^{(2)}a^{(1)}=(0.5447\times0.5744,\ 0.5447\times0.6457)=(\mathbf{0.3129},\ \mathbf{0.3517})$; $\partial L/\partial b^{(2)}=\mathbf{0.5447}$.

(b) $\sigma'=a(1-a)$: $(0.5744\times0.4256,\ 0.6457\times0.3543)=(0.2445,\ 0.2288)$. $\delta^{(1)}_1=0.5447\times0.7\times0.2445=\mathbf{0.0932}$; $\delta^{(1)}_2=0.5447\times(-0.5)\times0.2288=\mathbf{-0.0623}$.

(c) $\partial L/\partial w^{(1)}_{jk}=\delta^{(1)}_jx_k$: $\begin{pmatrix}0.0932&0.0466\\-0.0623&-0.0312\end{pmatrix}$; $\partial L/\partial b^{(1)}=(0.0932,\ -0.0623)$. All signs are the opposite of the lecture's $y=1$ case, as expected: the error $a-y$ changed sign.

(d) $[L(0.7001)-L(0.6999)]/0.0002=0.3129$, agreeing with backpropagation to four decimals.

Problem 5: One update and the vanishing gradient 20 marks

(a) Apply one gradient-descent step with $\eta=0.5$ to every parameter, using the gradients of Problem 4. [6]
(b) Repeat the forward pass with the new parameters. Did the prediction move towards $y=0$, and by how much did the loss change? [6]
(c) A network has ten sigmoid hidden layers. Give a lower bound on the factor by which the error signal can shrink between the output and the first layer (weights of size about 1), and explain the consequence. [5]
(d) Name two design choices that counter this and say why each works. [3]

Show full solution

(a) $w^{(2)}\leftarrow(0.7-0.1564,\ -0.5-0.1758)=(\mathbf{0.5436},\ \mathbf{-0.6758})$; $b^{(2)}\leftarrow0.1-0.2724=\mathbf{-0.1724}$. $W^{(1)}\leftarrow\begin{pmatrix}0.3534&-0.2233\\0.3312&0.6156\end{pmatrix}$; $b^{(1)}\leftarrow(-0.0466,\ 0.0312)$.

(b) $a^{(1)}=(\sigma(0.1952),\sigma(0.6702))=(0.5486,\ 0.6615)$; $z^{(2)}=0.5436(0.5486)-0.6758(0.6615)-0.1724=-0.3212$; $a^{(2)}=\mathbf{0.4204}$. The prediction fell from 0.5447 towards 0, and the loss fell from 0.7868 to $-\ln(0.5796)=\mathbf{0.5454}$.

(c) Each layer multiplies the signal by a weight and by $\sigma'(z)\le0.25$, so ten layers shrink it by at least $0.25^{10}\approx\mathbf{9.5\times10^{-7}}$. The first layers receive almost no gradient and barely learn: the vanishing-gradient problem.

(d) ReLU hidden units: derivative exactly 1 when active, so active paths do not shrink the signal. Residual connections $y=x+F(x)$: $\partial y/\partial x=I+\partial F/\partial x$ gives a direct path for the gradient. (Careful initialisation and normalisation layers also help.)

Problem 6 (bonus): Parameter counting and depth 20 marks

(a) Count the parameters of dense networks 20–64–32–5 and 784–128–64–10. [6]
(b) A one-hidden-layer network 20–$m$–5 is to have about the same number of parameters as 20–64–32–5. Find $m$. [4]
(c) The “tent” $g(x)=2\,\text{ReLU}(x)-4\,\text{ReLU}(x-0.5)$ maps $[0,1]$ onto $[0,1]$ with one peak. Composing it $k$ times gives $2^{k-1}$ peaks. How many ReLU units does the $k$-fold composition use, and how many would one hidden layer need for the same number of linear pieces? What does this say about depth? [10]

Show full solution

(a) $21\times64+65\times32+33\times5=1{,}344+2{,}080+165=\mathbf{3{,}589}$. $785\times128+129\times64+65\times10=100{,}480+8{,}256+650=\mathbf{109{,}386}$.

(b) $21m+(m+1)\times5=26m+5=3{,}589\Rightarrow m\approx137.8$; $m=138$ gives $3{,}593$. One wide layer can match the count, but not the hierarchy of features of features.

(c) Each composition uses 2 ReLUs, so $k$ layers use $2k$ units and produce $2^{k-1}$ peaks, that is $2^k$ linear pieces. One hidden layer of $n$ ReLUs gives at most $n+1$ pieces, so it needs about $2^k-1$ units. For $k=10$: 20 units in depth against about 1,023 in width. Depth can represent some functions exponentially more efficiently than width: the formal reason for “features of features”.
