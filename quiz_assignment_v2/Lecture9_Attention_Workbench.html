DEMO 1The positional encoding as a barcode

PE(pos, 2i) = sin(pos·ωᵢ), PE(pos, 2i+1) = cos(pos·ωᵢ), with ωᵢ = 10000−2i/d. Each row is the code added to one position: fast columns on the left, slow ones on the right. The dot product of two codes depends only on their offset k.

DEMO 4The n² price of a long context

Per layer, attention scores grow with the square of the sequence length n while the projections and feed-forward network grow linearly. Memory for the score matrices alone is n² × heads × bytes.
