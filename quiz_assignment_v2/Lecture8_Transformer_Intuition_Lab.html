DEMO 4Why divide by √dk?

One query is scored against eight keys whose components are random with mean 0 and variance 1. The typical size of a dot product grows like √dk. Without scaling, softmax puts nearly all the weight on one key and its gradient vanishes; with scaling the spread stays the same at any width.
